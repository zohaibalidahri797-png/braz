Developer docs

Everything you need to run, deploy and integrate BotDock Cloud.

🚀Quick start

Create an account → New bot → pick the Python keep-alive template → Create & deploy. Watch the build log live on the bot page. Your first bot runs in under a minute.

🔌API

Every dashboard action is a documented REST call. Full contract (auth, bots, deployments, logs, env vars, plans, health): docs/API-SPEC.md in the source repository.

📦Project format

ZIP/TAR.GZ up to 20 MB. Python projects: requirements.txt or pyproject.toml + main.py. Node/Bun: package.json (start script or index.js). Entry points are auto-detected and shown before deploy.

🤖Telegram tokens

Store your bot token as a secret environment variable (Env vars tab, "secret" checked). Values are encrypted at rest, write-only from the browser, and injected into the bot process at start.

☁️Self-hosting

Deploy the backend (Workers/OpenNext) and runtime service yourself — see docs/DEPLOYMENT.md, docs/STATIC-FRONTEND.md and docs/RUNTIME-DEPLOYMENT.md in the repository.
